如何接入现有主题系统： 将任一方案的色板落为 src/themes/themes.ts 的 48 键 token 体系 （20 基础色 + 24 样式级默认 + 4 配色方案专属），并在 themes/naiveMapping.ts 中完成 naive-ui 组件主题映射；组件内一律使用 var(--xxx)，即可在 「外观设置」中与现有 9 种 style 平级切换。完整映射规则与 token 对照表见 examples/README.md 设计文档。
每个示例页顶栏带「特效」按钮，演示外观设置页的特效开关机制 （切换 html.fx-off-<id> class 即时关闭对应装饰动画）。
