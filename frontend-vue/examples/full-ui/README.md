# ELA-Bot「完整 UI 功能版」演示页 — 交付说明

> 本目录为**只读演示交付物**（实现阶段已冻结）。本文件仅作使用说明，不参与页面逻辑。

## 用途

| 文件 | 内容 |
|------|------|
| `index.html` | 总览页：6 套风格的入口卡片 + 项目背景说明 |
| `aurora.html` / `matrix.html` / `zen.html` / `synthwave.html` / `ink.html` / `pixel.html` | 6 套完整功能页（10 模块：提供商 / 模型设置+Playground / 控制面板 / 提示词工坊 / 调试器 / 用户选项 / 外观设置 / Bot CRUD / 日志 / toast 弹窗） |

每页均为**零外部依赖单文件**（HTML+CSS+JS 内联，无网络请求），设计文档见 `../full-ui-design.md`，外部调研见 `../ui-research.md`。

## 打开方式

直接**双击**任意 html 文件即可（`file://` 协议），无需服务器、无需构建。推荐 Chrome / Edge / Firefox 最新版。

## 数据存储（每页独立）

- 各页使用**独立的 localStorage key**：`elabot-demo-state-v1-<风格名>`（如 `elabot-demo-state-v1-aurora`）。
- `file://` 下每页存储域天然隔离，6 页互不影响；删除某页 key 即恢复该页默认状态。
- 状态损坏时页面自动检测并重置（重置 toast）。

## 特效开关机制

- 外观设置视图内嵌**特效开关面板**；每页开关集合见页面内面板（aurora 3 项 / matrix 4 项 / zen 空态 / synthwave 4 项 / ink 2 项 / pixel 3 项）。
- 关闭即生效，通过 `html.fx-off-<id>` 类控制；开关状态持久化，刷新后保持且无闪烁（FOUC）。
- 另有独立「动画开关」（`html.anim-off`）；系统 `prefers-reduced-motion` 下全页动画自动关闭。

## 外观设置：切换与重置

- 外观视图内「风格卡」：当前风格可切换子项（如 zen 亮/暗），其余风格卡以链接跳转到对应 full-ui 页（不做跨风格 token 注入预览，见设计文档 §Q2 裁决）。
- 「重置演示数据」按钮：清空本页 localStorage 状态并刷新，恢复演示默认值。

## 已知遗留（最终交付披露）

| 项 | 说明 | 影响 |
|----|------|------|
| P7 体积债 | 6 页约 188-198KB（1000 进制）/ 2345-2940 行，超出设计上限 120KB / 2200 行 | 仅体积超限；零依赖单文件，功能完整，不影响 `file://` 加载 |
| matrix `--font` | 等宽替换基线字体（代码内已注释说明，纯终端语义） | 视觉偏离基线，功能无影响 |
| matrix 字典 | 2 个冗余 i18n 键 | 无功能影响，可后续清理 |
| providers 慢阈值 | 实装 400ms（设计 600ms） | 仅判定文案时机差异 |
| 省略字段标注 | 部分表单/卡片省略字段标注未全量覆盖 | 展示细节，数据为 mock |
| 测试脚本 | 验证脚本未入库（存于系统临时目录） | 无运行影响 |

其余范围外事项（真实后端调用、en 全量翻译、跨页共享等）见设计文档 §11。
